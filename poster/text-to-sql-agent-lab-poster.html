Design question

How can a learner judge whether a Text-to-SQL agent deserves trust, rather than trusting SQL merely because it executes?

Abstract & motivation

Text-to-SQL systems can return fluent, executable queries that still use the wrong business definition, table grain, filter, or output format.

Methods & results: cumulative component study

Task. “For orders placed in 2018, calculate the total number of orders for each month, from earliest to latest.” We held the model, evaluator, and read-only database fixed, then added generation components cumulatively. Each condition ran 10 times.

Key findings

Execution is not evidence of correctness. Trust requires inspectable evidence.

The lab makes retrieved context, generated SQL, execution, evaluation, and repair records available for review.

Responsible AI framework

ObservabilityReview inputs, retrieved context, generated SQL, execution, evaluation, and repairs.
Behavioral explainabilityChange one component and compare observable SQL and evaluation outcomes.
Transparency & accountabilityMake policies and responsibilities explicit before high-risk actions occur.
Evidence exposedRetrieved context, SQL, result, evaluation, repair history.
Human useDebug a run, compare configurations, approve or stop risky actions.

Implementation safeguards

Read-only SQL
Only one SELECT, WITH, or EXPLAIN statement is accepted.
Mutation blocking
Write, DDL, privilege, and locking statements are rejected.
Bounded execution
Eight-second timeout and a 200-row display limit.
Result evaluation
Compares returned answers rather than SQL strings.

Limitations & future work

  • Current evidence uses the Olist schema and one controlled benchmark question.
  • Components were added cumulatively; independent effects and interactions were not isolated.
  • Model outputs can vary by provider, model version, and run.
  • The policy interface is educational; it is not production RBAC or an enterprise audit system.
  • Next: evaluate across more questions, datasets, and models; add versioned experiment logs; and conduct a small user study comparing learners’ error detection and trust calibration with and without the XAI interface.
What this poster claimsMeasured, observable behavior for one fixed benchmark and configuration.
What it does not claimAccess to hidden reasoning, universal performance, or production-ready governance.
